## 截图口径

以下四张图片于 **2026-11-09** 使用 **0.2.0-alpha.4 实际生产 React 组件与样式**、项目自带的中文合成样例，在独立 Headless Chrome 浏览器夹具中交互捕获。每张顶部均标注 **离线组件演示 · 预设样例**。

它们不是设计稿，也不是整个已登录 DSH 的端到端安装验收。三个问题为**预设样例，不是 AI 发现**。图片不包含真实项目代码、提供方凭据或本机路径。

组件夹具不连接原生 Host，不进行模型调用，不替代原生模型确认、报告侧栏或人工写入流程的验收。外层页面只是展示容器，不冒充 DSH 导航、账号或连接状态；截图中的 Git 提交和内容摘要来自隔离的合成样例。

## 1. 问题列表与冻结证据

从候选问题查看需求关联、精确代码引文和需要澄清的问题。实现评估、意图、处置、验证分别展示，避免把“已回答”混为“已批准”。

![问题列表、需求关联和冻结代码证据](<images/01-findings-evidence.png>)

## 2. 打开需求冻结原文

点击 **查看冻结原文**，在审查保存的需求副本中高亮引用行。展示的是快照内容，不是此刻工作区里的同名文件。

![需求冻结副本和高亮引用行](<images/02-frozen-requirement.png>)

## 3. 查看冻结代码全文

点击 **查看冻结全文**，显示冻结提交、内容哈希、行号及高亮引用。短样例一次展示全部 7 行；较长文件每页最多 200 行。

![冻结代码全文、提交与高亮引用行](<images/03-frozen-source.png>)

## 4. 需求 → 实现映射

逐条查看需求的评估和证据。“静态证据支持”不是运行结果；“无证据”也不能断言整个系统都没实现。

![需求到实现映射及证据边界](<images/04-requirement-mapping.png>)
